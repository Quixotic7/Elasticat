regions

modifier 1,1
FN. Held with almost anything else; the norns K1 does the same job.
transport 3-5,1
REC, PLAY, STOP. Held as a scope modifier these become copy / clear / paste; held alone, STOP is cut & paste.
project pages 7-9,1
MASTER, FILE, PATTERN — the pages about the whole instrument.
parameter pages 11-16,1
TRIG, SOURCE, FILTER, AMP, FX, MOD — the per-track signal chain, in signal order.
loop / slice keys 1-16, rows 2-3
32 positions across the sample. Hold to move the played region live; on slice machines they fire slices. Row 3 is active only above a loop division of 16.
macros 1-4,4
MC1-MC4. Hold one and turn a destination to dial that macro’s depth to it.
track select 8-15,4
T1-T8. Press selects; FN+press mutes. Every page follows the selected track.
octave / memorize 1-2,5
Keyboard octave. With FN, memorise and recall the whole project to RAM.
pattern 8,5
Latch or hold the pattern-load overlay; FN opens pattern quantise.
scenes & crossfader 9-16,5
Scene A and B anchors at either end, with six glide keys between them.
mini keyboard 1-8, rows 6-7
One octave plus the root above. The gaps at 1,6 and 4,6 are the piano’s own missing black keys.
confirm & navigation 11-14, rows 6-7
YES / NO and the arrow cluster. Outside menus, NO is quick undo.
right-edge modifiers 16, rows 5-7
FILL and PAGE, held to overlay another mode onto the step row. SC-B anchors the same column.
step keys 1-16,8
The sequencer. Tap toggles a trig; hold and turn to parameter-lock it.

proposed — dedicated mute key at 16,4

Column 16 is already the modifier column. It holds MOD (16,1), SC‑B (16,5), FILL (16,6) and PAGE (16,7) — every one a held modifier or anchor, and nothing else. A mute key at 16,4 joins that column at the one row it belongs to: row 4 is the track row.

column 16 today 1 · MOD4 · free → MUTE5 · SC-B6 · FILL7 · PAGE

This is the only placement that needs no new gap. Putting mute in the 5‑7 gap would either read as a fifth macro or a ninth track depending on which side it sat, and a lone key floating mid‑row reads as unrelated to anything. At 16,4 it is adjacent to T8, but the column convention already tells you the right edge is a modifier, not a track.

hold MUTE → row 4 becomes eight mute toggles, all states visible at once. FN + MUTE latches the mode, matching how FN latches Fill. MUTE + hold a track solos it — reusing the tap‑versus‑hold distinction the step keys already teach.

The cost is honest: it spends the last free cell on the right edge, and mute moves off FN + track, which should keep working so existing muscle memory survives.
